# E33Chat · Minecraft 1.21.11 Fabric 版

> 基于 [E33EPUS/E33Chat](https://github.com/E33EPUS/E33Chat) 的 **1.21.11 Fabric 移植**，并在其上做了大量功能增强与缺陷修复。
> 本版**已不再只是「移植版」** —— 在保留原作者聊天界面风格的基础上，补齐了大量上游没有的交互与通知能力。

## 适配环境

| 项目 | 版本 |
|---|---|
| Minecraft | 1.21.11 |
| Fabric Loader | 0.19.3 |
| Fabric API | 0.141.5+1.21.11 |
| Java | 21 |

客户端模组。**服务端为可选**：安装后客户端可启用「服务器联动类功能」（消息元数据、精确引用跳转等）。

## 与原版的主要区别

### 聊天界面

- **主题系统**：暗 / 浅色主题 + 6 种强调色 + 自定义 HEX 配色，配置界面跟随主题
- 保留原版气泡、引用块、表情、图片消息等完整界面
- **右键二级菜单圆角化**：整块面板圆角 + 仅悬停行圆角高亮（与设置二级菜单观感一致）

### 交互增强

- **聊天文本选择**：鼠标拖选任意已渲染文本，`Ctrl+C` 复制；与链接点击、滚动条拖动互不冲突
- **系统消息可复制**：选中后 `Ctrl+C` 复制；右键系统消息**只显示「复制」**（无引用）
- **聊天输入框**：鼠标拖选、`Ctrl+A` 全选、复制/粘贴/剪切、选中后删除
- **引用块双击跳转**：双击消息里的引用行 → 滚动到被引用原消息并短暂高亮
  - 本地引用精确记录目标；**其他玩家的引用**在服务端安装本模组时通过 hash 链路精确定位，否则退化为内容匹配
- **链接点击**正确打开系统浏览器（修复了旧实现把 URL 当聊天内容发送的问题）
- **未知文本 ClickEvent 交回原版处理**（含 1.21.11 的 `Custom` / `ShowDialog`），插件自带的可点击菜单不再「点了没反应」

### 通知与免打扰

- **免打扰（DND）**
  - 左上角月亮按钮，**按会话独立**：公屏一份，每个私聊各自一份
  - 进入私聊视图时，同一按钮自动切换为「该私聊」的开关
  - 免打扰时：不弹灵动岛横幅、静默非 @ 提示音；**@提及 / 引用始终提醒**；**左下角红点保留**
  - 玩家列表中被免打扰的玩家显示**紫色月亮**，名字过长自动截断并加 `...`
- **公屏消息小窗**（聊天面板关闭时）
  - 左下角聊天图标上方显示最近 3 条公屏消息
  - 半透明圆角面板、发送者名与正文异色、长消息多行且不重复名字
  - 新消息从下往上顶、最旧淡出；**静默 5 秒**（可在设置中调整，1~60，热更新即时生效）后淡出
  - 公屏免打扰时不弹出；跟随 `F1` 隐藏
- **在线人数状态行**：侧边栏底部显示绿色 `【在线N人】`（含自己，与 TAB 口径一致）/ `【单人游戏中】`，水平居中并与输入框同一基线
- **玩家列表在线状态**：头像右下角小圆点（在线绿 / 离线灰）

### 兼容与稳定性

- **Jade（玉）软兼容**：显示 Jade 描述框时，通知横幅自动避让
- **皮肤解析异步化**：消除渲染线程阻塞造成的卡顿
- **主线程卡顿看门狗**：主线程长时间无 tick 时输出诊断日志
- **服务端联动通道按服务器白名单声明 + 自愈**（见下节）

## 服务端联动与网络说明（重要）

本模组在服务端安装时可以启用消息元数据、精确引用跳转等联动功能。但**自定义载荷通道声明发生在配置阶段**，此时客户端无法得知服务端是否安装本模组，因此采用分级策略：

| 场景 | 通道声明 |
|---|---|
| 单机 / 局域网（自己就是主机） | 直接启用 |
| 远程服务器 | **仅对已记住的 E33Chat 服务器**声明 |
| 服务器后来移除本模组 | 自动忘记该服务器，不再声明 |

「记住」是自动进行的：进服后检测到服务端也安装了本模组，会把该服务器地址写入 `config/e33chat/e33chat-servers.txt`，**下次连接生效**，玩家无需手动配置。

> ⚠️ **Paper 等严格服务端**：会对客户端声明的自定义载荷做校验，可能出现
> `Client disconnected with reason: Invalid custom payload payload!` 被踢出。
> 兜底方案：在 `config/e33chat/` 下放置一个名为 `no-custom-channels.flag` 的空文件，即可**完全关闭通道声明**（服务器联动功能随之不可用）。

## 配置

- 配置文件：`config/e33chat/e33chat-client.json`
- 图形界面：模组菜单 → 配置界面（分类开关，含 HUD / @提醒 / 主题 / 气泡等）

部分新增配置项：

| 配置项 | 说明 |
|---|---|
| `themeAccent` / `themeCustom` | 强调色 / 自定义配色 |
| `dndEnabled` | 公屏免打扰 |
| `dndWhisperPlayers` | 已设为免打扰的私聊玩家名单 |
| `publicOverlayEnabled` | 公屏消息小窗开关 |
| `publicOverlayIdleSeconds` | 小窗静默淡出秒数（1~60） |
| `redDotEnabled` | 左下角聊天图标红点 |
| `mentionBannerEnabled` / `systemBannerEnabled` | 灵动岛横幅开关 |

## 已知限制

- **首次**连接某个 E33Chat 服务器时不会立即启用联动（协议时序限制），**重连一次**即可生效
- 纯插件服 / 原版服无法提供完整的私聊联动，客户端只能按文本格式推断
- 引用精确跳转：本地引用精确；他人引用在服务端安装本模组时精确，否则按内容就近匹配（内容完全相同的多条消息可能落到邻近那条）
- 公屏小窗只在聊天面板关闭时显示
- 免打扰的横幅/声音拦截仅作用于本模组的通知系统（不影响原版与其它模组）
